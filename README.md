[5:54 am, 29/7/2026] Harish Mugadur: # House Price Prediction

## Project Overview
This project predicts house prices in Bengaluru using Machine Learning. It uses historical house data to estimate the price of a house based on different features.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning Model
- House Price Prediction
- Streamlit Web Application

## Technologies Used

-  Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Dataset
Bengaluru House Price Dataset
